# Partner Platform — Authors & Contributors

This file lists the people and organisations who have contributed to the
Partner Platform. It is maintained manually — if your name is missing,
please open a pull request to add it.

---

## Core Team

The Partner Platform was created and is maintained by the engineering team at
the National Payments Corporation of India (NPCI). The same maintainer team
owns [AtOM](https://github.com/npci/atom-network-platform), the
Authority-side platform this one talks to — see [`CODEOWNERS`](CODEOWNERS).

---

## Contributors

Contributions are tracked via git history and GitHub pull requests.
All contributors who have signed off commits with the DCO are credited
through the git log.

To see all contributors:

```bash
git log --format="%aN <%aE>" | sort -u
```

## How to Contribute

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on how to contribute
to this project.

Every commit must carry a DCO sign-off (`git commit -s`) — see [DCO.md](DCO.md).
